# Reference transcripts

One `<id>.txt` per manifest entry, plain text, no speaker labels and no
timestamps. `score.py` normalizes casing and punctuation away, so only the words
matter — but every word in the file counts, which is why nothing else may live
in it.

## These must be corrected by ear

A reference produced by the same model you are measuring scores 0% WER against
itself and tells you nothing. Drafts generated by `transcribe` are a typing
aid, not ground truth. Correct one against the audio before trusting any number
that comes out of `score.py`.

Generate a draft:

```
./app/.build/release/transcribe --audio eval/audio/<id>.wav \
    --tier accurate --language tl --no-diarize --format txt --out /tmp/<id>.txt
```

Strip the header, correct the body, save as `refs/<id>.txt`.
